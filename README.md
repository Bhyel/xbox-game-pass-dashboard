# 🎮 Dashboard de Vendas: Xbox Game Pass (Projeto DIO)

## 📋 Sobre o Projeto
Este dashboard foi desenvolvido como parte de um desafio da DIO (Digital Innovation One). O objetivo é analisar o ecossistema de assinaturas do Xbox, monitorando faturamento, tipos de planos e o comportamento de retenção dos usuários ao longo do ano de 2024.


## 📈 Análise de Negócio e Insights (T1 vs T4)

Abaixo, os principais indicadores que mostram a evolução do faturamento e da base de clientes entre o primeiro trimestre (T1) e o quarto trimestre (T4).

### 1. Performance de Receita
Houve um salto expressivo no faturamento, evidenciando um crescimento agressivo:
*   **EA Play Season Pass:** Crescimento de **116%** (de R$ 360,00 para R$ 780,00).
*   **Minecraft Season Pass:** Crescimento de **121%** (de R$ 460,00 para R$ 1.020,00).
*   **Xbox Game (Geral):** A receita total mais que dobrou, passando de R$ 948,00 para R$ 2.005,00.

### 2. Volume de Assinantes
A base de usuários cresceu de forma equilibrada em todas as categorias:
*   **Distribuição:** Em T1, cada plano (Ultimate, Standard e Core) tinha cerca de 12 assinantes. Em T4, essa média subiu para **26 assinantes por tipo**.
*   **Consistência:** O crescimento não foi isolado, o que mostra que a plataforma atrai diferentes perfis de jogadores.

### 3. Retenção e Fidelização
O indicador de **Renovação Automática** mostra uma tendência positiva para a receita recorrente:
*   **Aumento de Adesão:** Saltamos de 18 para **39 usuários** com renovação ativa no T4.
*   **Saúde do Negócio:** O número de usuários que optam pela renovação automática agora supera os que preferem o controle manual, garantindo maior estabilidade financeira.

---

## 💡 Conclusão Estratégica
O desempenho superior no **T4** é fortemente impulsionado pela sazonalidade (Black Friday e Festas). O **Minecraft Season Pass** consolidou-se como o produto de maior valor bruto. 

**Recomendação:** Campanhas de pacotes (bundles) entre o plano Core e o passe do Minecraft podem ser uma excelente estratégia para converter novos usuários logo no início do próximo ano.
